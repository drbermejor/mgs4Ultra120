[b]MGS4 Ultra120 v0.3.4-alpha.7 - expanded Native Centered HUD[/b]

This update expands the optional experimental 16:9 HUD/interface mode:

[list]
[*]The pause map and its live markers now keep the correct aspect.
[*]The Codec frame is centered, but its live in-engine 3D content can still appear horizontally compressed.
[*]Mission Briefing has a partial guarded adjustment, but control and ticker text can still overflow the centered canvas.
[/list]

The 3D game world still renders across the full ultrawide screen. The existing ultrawide, FOV, 120 FPS, supersampling, high-resolution reticle, controller and launcher-bypass features are unchanged.

[b]Native Centered HUD is still experimental and disabled by default.[/b] The pause-map correction and partial Codec/briefing adjustments use strict observed routes. The Codec and briefing limitations above are already known, and every act, language, content variant, transition and Proton setup has not been tested. If you see a problem, close the game and disable Native Centered HUD in the configurator.

Existing HUD opt-in choices are preserved during a guided update. The controller-profile fix remains opt-in; enable it only if needed, and leave it disabled for keyboard/mouse or controller plus mouse/gyro input.
