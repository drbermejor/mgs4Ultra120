[b]MGS4 Ultra120 v0.3.3-alpha.1[/b]

This is the recommended current alpha for Windows and Linux/Proton. It fixes the FOV distortion seen in the weapon menu and includes ultrawide rendering, corrected high-frame-rate support, controller fixes and the optional launcher bypass.

The final Windows package was tested at 3440x1440 in gameplay, the weapon menu and the previously problematic in-engine cinematics.

[b]Recommended settings[/b]

[list]
[*][b]Most stable:[/b] leave [i]Experimental native FOV[/i] disabled. Ultrawide correction still works with the original vertical FOV.
[*][b]Expanded 21:9 FOV:[/b] enable it and use the tested 1.200 recommendation. Higher values are accepted but untested; check [i]mgs4_ultrawide.log[/i] and disable the option if a scene behaves incorrectly.
[*][b]Supersampling:[/b] experimental and disabled by default. Keep internal width below 4096 to avoid aiming-reticle problems.
[/list]

[b]Important: remove old builds first[/b]

Do not mix files from different versions. Uninstall or completely remove the previous MGS4 Ultra120 build before installing this one. Guided setup detects known duplicate ASI loaders and old project ASIs.

[b]Brief manual installation[/b]

1. Close the game and remove the previous patch.
2. Extract the Manual ZIP.
3. Copy everything into the folder containing [i]mgs4.exe[/i].
4. Keep the included [i]scripts[/i] folder and launch through Steam.

[code]MGS4\winmm.dll
MGS4\mgs4_ultrawide.ini
MGS4\scripts\MGS4Ultra120.asi[/code]

For corrected 120 FPS, manual users must also copy [i]MGSFPSUnlock.asi[/i] and [i]MGSFPSUnlock.ini[/i] from the official release into [i]MGS4\scripts[/i]:

[url=https://github.com/cipherxof/MGSFPSUnlock/releases/tag/0.1.0]MGSFPSUnlock 0.1.0[/url]

[b]Unsigned installer[/b]

The Setup EXE is not digitally signed, so Windows or a browser may show an unknown-publisher warning. The EXE is optional: use the Portable or Manual ZIP if preferred. The project is open source, contains no game files and never modifies [i]mgs4.exe[/i].

[b]Legacy fallback[/b]

v0.3.1-alpha.5 remains available as the previously validated renderer-only fallback. Remove the current build completely before returning to it.
