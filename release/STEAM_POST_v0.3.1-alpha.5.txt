[b]Correction to the previous description[/b]

The alpha.5 ASI actually distributed uses the validated renderer-level FOV correction. Previous notes incorrectly stated that the downloadable package also synchronized the game's CPU culling frustum. It did not.

FOV values above 1.000 can still reveal side pop-in, and extreme close-ups can briefly return to the original framing. These remain open limitations.

The installer is open source but unsigned. Use the portable or manual ZIP if you prefer not to run the EXE.
