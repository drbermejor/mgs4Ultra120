[b]MGS4 Ultra120 v0.3.3-alpha.1 - experimental FOV correction[/b]

This alpha fixes the WeaponWindow distortion reported after the previous FOV change. The multiplier is now applied once, only on the primary native camera route, instead of being repeated during downstream camera rebuilds.

Windows testing at 3440x1440 and FOV 1.200 passed gameplay, the weapon menu and the previously problematic in-engine cinematics. 1.200 is the tested 21:9 recommendation and maximum under the corrected model; 1.000 keeps the original vertical FOV.

[b]The native FOV option is still experimental.[/b] If you see instability or a scene-specific regression, disable [i]Experimental native FOV[/i] in the configurator. Ultrawide aspect correction remains active; only the expanded FOV is removed.

[b]Legacy fallback[/b]

v0.3.1-alpha.5 remains available as the previously validated renderer-only fallback. Try disabling [i]Experimental native FOV[/i] in this release first. If you return to alpha.5, completely remove the current build before installing it; never mix files from both releases.

Values above 1.000 can reveal actors, geometry or animation transitions near the edges before the original shot intended them to enter. This can happen even when projection and culling are correct.

[b]Important: remove old builds first[/b]

Do not mix files from different releases. Use the old package's uninstaller, or remove old MGS4 Ultra120/ASI-loader copies after backing up files owned by other mods. A correct manual layout has only:

[code]MGS4\winmm.dll
MGS4\mgs4_ultrawide.ini
MGS4\scripts\MGS4Ultra120.asi[/code]

Do not leave a second Ultimate ASI Loader under names such as dinput8.dll, d3d11.dll, wininet.dll or winhttp.dll, and do not keep renamed old MGS4 Ultra120 ASIs. Guided setup now detects known duplicates and stops with the exact file list; it never deletes unknown third-party DLLs automatically.

The language fix is also included. Spanish was verified in game. The manual ZIP does not install the launcher bypass, so manual users choose their language in the official Unity launcher.
