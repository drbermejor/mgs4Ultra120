MGS4 ULTRA120 - COPY-ONLY MANUAL INSTALL

FOV 1.200 is the tested 21:9 recommendation. Higher valid values are accepted
without a hard limit, but are untested and can show actors, geometry or
transitions at cinematic edges earlier than intended. Check
mgs4_ultrawide.log when troubleshooting custom values.

CORE / NORMAL-FPS ROUTE

1. Close the game.
2. Open the folder that directly contains mgs4.exe, normally:

   ...\Steam\steamapps\common\METAL GEAR SOLID 4\MGS4

3. Copy everything inside this extracted folder into that MGS4 folder.
4. Confirm:

   MGS4\winmm.dll
   MGS4\mgs4_ultrawide.ini
   MGS4\mgs4_centered_hud_16x9.ini
   MGS4\scripts\MGS4Ultra120.asi
   MGS4\scripts\MGS4CenteredHUD16x9.asi

5. Launch normally through Steam.

EXPERIMENTAL OPTIONS (OFF BY DEFAULT)

Close the game before editing either INI.

- Real-time cinematic FOV: in mgs4_ultrawide.ini set
  ExperimentalCinematicFOV=1. Keep CinematicFOVMultiplier=inherit to use the
  gameplay value, or enter a separate finite value of 0.500 or greater.
- Centered 16:9 HUD: in mgs4_centered_hud_16x9.ini set Enabled=1. This option
  requires DirectX 12.

To return to the reference behavior, set ExperimentalCinematicFOV=0 and
Enabled=0. The centered-HUD ASI may remain installed: when disabled it exits
without installing D3D12 hooks. If a problem remains, completely remove this
build and reinstall the v0.3.3-alpha.1 legacy fallback release.

OPTIONAL CORRECTED 120 FPS

1. Download MGSFPSUnlock.zip only from:
   https://github.com/cipherxof/MGSFPSUnlock/releases/tag/0.1.0
2. Open MGSFPSUnlock\scripts inside that ZIP.
3. Copy only MGSFPSUnlock.asi and MGSFPSUnlock.ini to MGS4\scripts.
4. Do not copy d3d11.dll, winhttp.dll or wininet.dll. The included winmm.dll
   already loads both ASIs.
5. Confirm MGSFPSUnlock.ini says: TargetFrameRate = 120

Thanks to cipherxof for the improved FPS unlock implementation.

This copy-only route runs no installer or script, creates no shortcuts and does
not install the optional Unity-launcher bypass. Back up every existing file with
the same name. If another mod already owns a compatible x64 ASI loader, keep it
and copy only the ASI/INI files.

Launch through Steam and choose the language in the official Unity launcher.
The Language= value in mgs4_ultrawide.ini is used only by the optional direct
wrapper installed by guided setup; the copy-only package does not install it.
